## 本轮完成

### 修复「Safari 点菜单全部无响应」（核心）

根因：Safari 的 `chrome.permissions.contains({permissions:['downloads']})`
**同步抛错**（`downloads` 不是合法权限名），而上游 `permissions.js` 在模块顶层调用它，
未捕获异常导致整个后台 bundle 在求值阶段中止，`runtime.onMessage` 从未注册。
弹窗能渲染但所有命令发出去都无人应答。

修复要点（全部在 `src/fork/`）：

- `api-stubs.js`：剔除 Safari 不认识的权限名 + try/catch 兜底
- `guard.js`（新增）：`safePatch` / `trySet` / 早期异常捕获 → `localStorage['fork:log']`
- 三处回调丢失补丁（`storage.local.get`、`tabs.query`、async stub）改用双模式实现
- `windows.getAll()` 等返回值规整，避免 init 依赖 reject
- `tabs.create` 降级重试（逐级剔除 `openerTabId` / `cookieStoreId` / `index`）
- `diagnostics.js`：init 看门狗 + 命令级错误日志

详细排查过程：[Safari弹窗菜单无响应根因定位与修复](20261122-2345-Safari弹窗菜单无响应根因定位与修复-Claude-Sonnet-4.5.md)
