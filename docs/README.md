# 文档索引

命名规则（全项目统一）：

```
docs/YYYYMMDD-HHMM-<标题>-<模型名>.md
```

例：`docs/20261009-0055-Safari扩展消失根因与安装步骤补齐-GPT-6.md`

- 时间戳为「年月日-时分」连写（8 位数字 + 连字符），取自文档撰写时刻。
- 末尾必须带**撰写模型的名称**（如 `-GPT-6`），用于区分不同模型产出的记录。
- 新增文档必须在本索引登记一条，否则等于没写。
